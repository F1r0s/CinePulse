# Cine4Life 🎬

**Cine4Life** is a premium, ad-free streaming platform that brings the magic of cinema directly to your screen. Built with a focus on speed, simplicity, and a superior user experience, Cine4Life offers thousands of movies and TV shows completely free of charge.

## ✨ Key Features

- **100% Free Streaming** - No subscriptions, no hidden costs, no interruptions.
- **Ad-Free Experience** - Enjoy your favorite content without annoying ads.
- **High Quality** - Stream in HD for a crisp, clear viewing experience.
- **Extensive Library** - Access a vast collection of the latest and classic movies and TV shows.
- **Fast & Responsive** - Built on modern technology for instant loading and seamless playback.
- **Clean UI** - A beautiful, intuitive interface that makes finding something to watch a joy.
- **Always Available** - 24/7 access to thousands of titles.

## 📂 Project Structure

- `index.html`: The homepage with featured collections and quick access.
- `movies.html`: Browse and discover movies by genre or trending status.
- `tv.html`: Explore the latest and greatest TV shows.
- `watch.html`: The dedicated player page for watching content.
- `style.css`: Global styles for the site.
- `app.js`: Core JavaScript logic for TMDB API integration and UI controls.
- `vercel.json`: Deployment configuration for Vercel.

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/F1r0s/CinePulse.git
   cd CinePulse
   ```

### Running Locally

To run this project locally, you can simply open the `index.html` file in your browser. For the best experience and to ensure all features work correctly (especially if the site uses external APIs), a simple HTTP server is recommended.

Using Python:
```bash
# In the project directory
python -m http.server 8000
```
Then open [http://localhost:8000](http://localhost:8000) in your browser.
